# ✂️ Beauty Salon Management System

Уеб приложение за управление на козметичен салон, разработено с **ASP.NET Core MVC**, **Entity Framework Core** и **Bootstrap 5**.

---

## 🌟 Основни функционалности

* **Управление на Услуги (Services):** Пълен CRUD (създаване, преглед, редактиране и изтриване) на предлаганите козметични услуги с цена и описание.
* **Категоризация (Categories):** Организиране на услугите в отделни категории (напр. *Маникюр*, *Фризьорство*, *Козметика*).
* **Резервации (Appointments):** Запазване на часове от клиенти с избор на дата, час, услуга и данни за контакт.
* **Модерен UI / UX:** Адаптивен дизайн с Bootstrap 5, иконки от Bootstrap Icons, Hero баннер и структурирани форми.

---

## 🛠 Използвани технологии

* **Backend:** C# / .NET 8 (ASP.NET Core MVC)
* **ORM:** Entity Framework Core
* **Database:** Microsoft SQL Server
* **Frontend:** Razor Views, Bootstrap 5, Bootstrap Icons, HTML5, CSS3
